# Pixel Asset Rules

이 디렉터리는 실제 게임용 픽셀 에셋을 저장합니다.

## 공통 규칙

- 투명 배경 PNG 사용
- 정수 배율 확대만 사용
- 캐릭터 레이어는 동일한 캔버스 크기 유지
- 얼굴 중심, 목, 골반, 발바닥 앵커 좌표 고정
- 파일명은 영문 소문자와 하이픈 사용
- 완성 장면 이미지보다 재사용 가능한 레이어와 스프라이트 시트를 우선 제작
