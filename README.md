# English Runner

영어 단어를 외우며 캐릭터의 체중, 피부, 외모와 아이돌 성장 단계를 관리하는 모바일 웹 게임 프로토타입입니다.

## 현재 구현

- 모바일 세로형 홈 화면
- 런닝머신 위 러너의 CSS 임시 캐릭터
- 체중, 피부 상태, 연속 학습, 누적 단어 표시
- `localStorage` 기반 플레이어 상태 저장
- 하루 이상 미접속 시 체중 증가 및 피부 상태 감소
- 샘플 영어 단어 퀴즈와 정답 보상
- 피부관리, 성장 기록, 옷장 등 후속 메뉴 자리 구성

## 실행

별도 빌드 과정 없이 `index.html`을 브라우저에서 열면 됩니다. 로컬 서버를 사용하면 더 안정적입니다.

```bash
python -m http.server 8000
```

브라우저에서 `http://localhost:8000`으로 접속합니다.

## 픽셀 에셋 구조

현재 캐릭터는 UI 검증을 위한 CSS 임시 도형입니다. 실제 제작 에셋은 아래 구조로 교체할 예정입니다.

```text
assets/pixel/
├── character/
│   ├── body/
│   ├── face/
│   ├── hair/
│   ├── glasses/
│   ├── clothes/
│   └── animation/
├── equipment/
│   └── treadmill/
├── background/
└── ui/
```

모든 캐릭터 레이어는 동일한 캔버스 크기와 발바닥·얼굴·의상 앵커 좌표를 사용해야 합니다.
